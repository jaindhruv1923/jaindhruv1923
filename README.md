## 🔍 How I Work

> Every project README, dashboard, and case study I ship is written against the actual notebook or dataset that produced the numbers in it — not the other way around.

Across my own projects I've caught and fixed real mismatches before publishing: a dashboard metric that disagreed with its own source notebook, a raw-row count that turned out to be a file's *line count* rather than its actual record count, a cluster count off by one from what the model actually produced.

  <img src="https://raw.githubusercontent.com/jaindhruv1923/Project-Profitara-Retail-BI-Pipeline/main/02_health_scorecard.png" width="48%"/>
  <img src="https://raw.githubusercontent.com/jaindhruv1923/Project-Profitara-Retail-BI-Pipeline/main/04_churn_distribution.png" width="48%"/>

[![Repo](https://img.shields.io/badge/Repo-View_on_GitHub-181717?style=for-the-badge&logo=github)](https://github.com/jaindhruv1923/Project-Profitara-Retail-BI-Pipeline)
[![Live](https://img.shields.io/badge/Live-Streamlit_Dashboard-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://project-profitara-retail-bi-pipeline.streamlit.app/)

End-to-end retail analytics pipeline on a 10,000-row India quick-commerce transaction dataset — 4,918 orders, 1,448 customers, ₹66.95L total revenue.

- 🌲 Random Forest CLV model — R² = 0.930
- 📉 Logistic Regression churn classifier — AUC 0.91, 361 at-risk customers flagged
- 🧩 K-Means segmentation — 119 "Champion" customers
- 🔗 Apriori market-basket analysis — 52 cross-sell rules
- 📊 13-page Streamlit dashboard + Power BI build + PostgreSQL/DuckDB SQL layer

`Python` `scikit-learn` `Streamlit` `PostgreSQL` `DuckDB` `Power BI`

### 🕵️ Naukri Saaf — Ghost Job Listing Detection Platform

<p align="center">
  <img src="https://raw.githubusercontent.com/jaindhruv1923/Project-Naukri-Saaf-Job-Listings-Analysis/main/media4.png" width="48%"/>
  <img src="https://raw.githubusercontent.com/jaindhruv1923/Project-Naukri-Saaf-Job-Listings-Analysis/main/Screenshot_2026-07-21_142519.png" width="48%"/>
</p>

[![Repo](https://img.shields.io/badge/Repo-View_on_GitHub-181717?style=for-the-badge&logo=github)](https://github.com/jaindhruv1923/Project-Naukri-Saaf-Job-Listings-Analysis)
[![Live](https://img.shields.io/badge/Live-Streamlit_Dashboard-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://project-naukri-saaf-job-listings-analysis.streamlit.app/)

ML pipeline on 3,000 real listings scraped from LinkedIn, Indeed, and Glassdoor (cleaned to 2,851), flagging 29.3% as likely ghost postings under a weak-supervision scheme.

- 🤖 5 classifiers benchmarked — best: GBM, AUC 0.716
- 🔬 SHAP explainability per listing
- 🧑‍💼 5 employer behavioral clusters, incl. "High-Risk Ghost Poster": 1,361 employers
- 🧩 Chrome extension — scores listings 100% locally, zero network calls
- 📊 7-tab Streamlit dashboard + Power BI dashboard + full SQL layer

`Python` `scikit-learn` `SQL` `Chrome Extension` `Power BI` `SHAP`
